The reply gives the next physical steps one at a time: stop the test by holding the power button (not Esc or a restart, which would boot Windows on the bad RAM), unplug the mains cable, leave one stick in the first slot and run the memory test, then the other stick in the same slot. It says how to read the outcomes: one stick fails means that stick is bad; both fail in the same slot means testing the other slot, then the board, memory controller or power supply.
